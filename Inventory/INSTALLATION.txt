INSTALLATION STEPS:
================================================================================

STEP 1: EXTRACT PROJECT FILES
  1. Extract Inventory folder to: C:\xampp\htdocs\
  2. Result: C:\xampp\htdocs\Inventory\

STEP 2: START XAMPP SERVICES
  1. Open XAMPP Control Panel
  2. Click "Start" button for Apache
  3. Click "Start" button for MySQL
  4. Wait 5 seconds for both to show GREEN

STEP 3: CREATE AND IMPORT DATABASE
  1. Open browser → http://localhost/phpmyadmin
  2. Click "SQL" tab at top
  3. Open file: Inventory/database_schema.sql (with text editor)
  4. Copy entire content
  5. Paste into SQL window in phpMyAdmin
  6. Click "Go" button
  7. Wait for success message ✓

STEP 4: VERIFY DATABASE IMPORT
  1. In phpMyAdmin left panel
  2. Look for "pharmacy_inventory" database
  3. Click it to expand
  4. Should see 10 tables:
     - roles
     - users (with 3 default accounts)
     - categories (with 5 samples)
     - suppliers (with 3 samples)
     - products (with 8 samples)
     - inventory_transactions
     - sales
     - demand_forecasts
     - forecast_history
     - activity_logs

STEP 5: ACCESS THE SYSTEM
  1. Open browser
  2. Go to: http://localhost/Inventory/
  3. You'll see login page with MangaRingMed branding
  4. System automatically redirects to login if not logged in

STEP 6: LOGIN WITH DEMO ACCOUNT
  Choose one of three demo accounts:
  
  ADMIN (Full Access):
    Email: admin@mangaringmed.com
    Password: admin123
  
  OWNER (Inventory Manager):
    Email: owner@mangaringmed.com
    Password: admin123
  
  STAFF (Basic Operations):
    Email: staff@mangaringmed.com
    Password: admin123

STEP 7: EXPLORE THE SYSTEM
  1. View dashboard specific to your role
  2. Check sidebar for available features
  3. Try adding a product as Admin
  4. Record stock movements as Staff
  5. View forecasts as Owner

DATABASE CONFIGURATION:
================================================================================

If you need to change database credentials, edit:
  File: includes/config.php
  
  Change these values:
  define('DB_HOST', 'localhost');
  define('DB_USER', 'root');
  define('DB_PASS', '');              // Add if MySQL needs password
  define('DB_NAME', 'pharmacy_inventory');

Note: Default XAMPP MySQL has NO PASSWORD (empty string '')

================================================================================
TROUBLESHOOTING:
================================================================================

PROBLEM: "Can't connect to database" error
SOLUTION:
  1. Verify MySQL is running in XAMPP (green indicator)
  2. Check config.php credentials
  3. Verify pharmacy_inventory database exists in phpMyAdmin

PROBLEM: "Database not found" on login
SOLUTION:
  1. Open phpMyAdmin
  2. Re-import database_schema.sql
  3. Verify all tables exist

PROBLEM: Login page shows but can't login
SOLUTION:
  1. Make sure demo users were created (check users table)
  2. Verify password is exactly: admin123 (case-sensitive)
  3. Check if user status is "active"

PROBLEM: Blank pages or errors
SOLUTION:
  1. Check Apache error log in XAMPP
  2. Verify PHP error_reporting is on
  3. Ensure all .php files were extracted
  4. Check file permissions (should be readable)

PROBLEM: Forecast not showing
SOLUTION:
  1. Need at least 7 days of historical sales data
  2. Check if sales records exist in database
  3. Forecasts calculate from sample data provided
